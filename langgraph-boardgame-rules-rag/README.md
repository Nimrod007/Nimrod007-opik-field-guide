# langgraph-boardgame-rules-rag

A rules referee for three invented board games, traced and scored with Opik.

Run `uv run rulesrag demo` (needs `OPENAI_API_KEY` and a running Opik) to ask a few questions and compare two experiments, then open the `langgraph-boardgame-rules-rag` project. Offline tests: `OPIK_TRACK_DISABLE=true uv run pytest`.
